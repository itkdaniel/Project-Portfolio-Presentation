# Crypto Wallet Service

Nexus HD Wallet service — manage wallets, addresses, balances, and transactions.

## Port
8102

## Tech Stack
- FastAPI
- SQLAlchemy (Async)
- PostgreSQL
- Pydantic Settings

## Endpoints
- `/v1/wallet/wallets`: Wallet CRUD
- `/v1/wallet/addresses`: Address management
- `/v1/wallet/balances`: Balance tracking
- `/v1/wallet/transactions`: Transaction history
